# Install UV

### Linux

```bash
sudo apt update # step 1
curl -LsSf https://astral.sh/uv/install.sh | sh # step 2
source ~/.bashrc # step 3
```

# create a virtual environment

## Linux

```bash
uv venv .venv # step 1
source venv/bin/activate # step 2
```

# Install dependencies

## Linux

```bash
uv install -r requirements.txt # step 1
```
